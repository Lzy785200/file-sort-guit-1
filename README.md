# Python GUI 文件整理工具
大一自学Python练手项目，带图形界面，一键分类本地文件

## ✨功能
- tkinter图形窗口，可视化选择文件夹
- 根据文件后缀自动新建文件夹归类
- 支持图片、文档、视频、音频、程序等多种格式
- 增加路径校验，判断路径是否存在、是否文件夹，做异常防护
- 弹窗提示成功/报错

## 🖥️运行环境
Python3，自带tkinter库，无需额外pip安装

## 📖使用方法
1. 运行 script5.py
2. 点击按钮，选择需要整理的文件夹
3. 程序自动分类文件

> ⚠️注意：不要直接整理C盘系统目录，优先新建测试文件夹测试！
